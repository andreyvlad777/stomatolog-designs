# Три концепции сайта стоматолога

Три независимых адаптивных HTML-макета для сравнения дизайна персонального сайта врача-стоматолога. Все страницы являются демонстрационными.

## Открыть в браузере (GitHub Pages)

- [Сравнить все три дизайна](https://andreyvlad777.github.io/stomatolog-designs/)
- [01 — CLEAR: медицинский](https://andreyvlad777.github.io/stomatolog-designs/01-clear/)
- [02 — WARM: персональный](https://andreyvlad777.github.io/stomatolog-designs/02-warm/)
- [03 — NOIR: премиальный](https://andreyvlad777.github.io/stomatolog-designs/03-noir/)

В каждом варианте: первый экран, информация о враче, услуги, порядок приёма, контакты и демонстрационная форма обращения. Страницы автономны: внешний JS и CSS не требуются.

## Персонализация

В конце каждого файла `index.html` найдите блок `<script type="application/json" id="site-config">` и заполните имя врача (`doctorName`), специальность (`specialty`), фотографию (`photo`), телефон, WhatsApp, Telegram, email, адрес и режим работы. Остальные рекламные тексты и демонстрационные названия нужно скорректировать в HTML.

**Форма не передаёт данные на сервер.** При наличии WhatsApp или email формируется обращение, которое посетитель отправляет самостоятельно. Для полноценной записи потребуется отдельный сервис записи и корректное оформление обработки персональных данных.

## Важно перед публичным использованием

Имя, квалификация врача, лицензия медицинской организации, перечень услуг и данные для связи должны соответствовать действительности. Проверить местные требования к информации об оказании медицинских услуг и персональным данным.

**Исходные файлы:** `01-clear/index.html`, `02-warm/index.html`, `03-noir/index.html`. Главная страница `index.html` демонстрирует все три оформления.
